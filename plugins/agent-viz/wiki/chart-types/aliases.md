# Chart name aliases

A chart name maps to the page that covers it, or to a plain statement that nothing here does.

Readers arrive with a name, not a data relationship, and the names are not stable. No source in this corpus defines "spine chart" ([spine-chart.md](spine-chart.md)) or "streamgraph" ([streamgraph.md](streamgraph.md)). No page is named "joyplot", though [ridgeline-plot.md](ridgeline-plot.md) covers the form. Three names, "mosaic plot", "heat map" and "range plot", collide badly enough to get sections below.

## The status column

A name mapping is not an empirical claim, so `evidence-backed`, `authority-asserted` and `contested` do not apply. A row carries provenance instead:

- **Recorded**: the name appears in a source opened in this corpus, and the row names it.
- **Stipulation**: this page or another uses the name and says so, with nothing behind it, as [spine-chart.md](spine-chart.md) does.
- **In circulation**: the name is in use in the field, and no source here defines it.

A recorded name is not a definition. Most recorded names come from [Schwabish's](../sources/schwabish.md) contents pages, and his prose is unread here. That shows where a published catalog files the name, not what he means by it. Any FT name and gloss can be cited from the complete listing on the [FT source page](../sources/ft-visual-vocabulary.md).

## The three collisions

None can be fully resolved from this corpus.

### "Mosaic plot"

**The two referents.** The chart on [marimekko-chart.md](marimekko-chart.md), a stacked bar whose bars also vary in width so every segment's area is its share of the grand total. And a statistical-graphics display built from a contingency table.

**Who files what.** [Schwabish](../sources/schwabish.md) catalogs **Marimekko and Mosaic** as one entry under Comparing Categories. That is the only vouched statement in this wiki that the two names cover one form, and it vouches a catalog entry, not an argument.

**Wilke's definition.** [Wilke](../sources/wilke-fundamentals.md) defines the term in running text and files it with the treemap under proportions: "unlike in a stacked bar plot, in a mosaic plot both the heights and the widths of individual shaded areas vary." That is the marimekko drawing. He adds the condition the statistical usage turns on: "This is a critical condition for a mosaic plot: Every categorical variable shown must cover all the observations in the dataset." So the referents are one drawing under a constraint, which a contingency table supplies.

**What is still open.** Whether everyone who says "mosaic plot" means the condition too. Few's unread "Are Mosaic Plots Worthwhile" ([stephen-few.md](../people/stephen-few.md)) would show how contested the term is in practice.

### "Heat map"

**The referents, at least four.** A grid of equal cells with two keyed axes and a color per cell ([heatmap.md](heatmap.md)). The same grid holding correlation coefficients ([correlation-matrix.md](correlation-matrix.md)). A [choropleth map](choropleth-map.md), which ordinary usage calls a heat map though its geometry comes from a base geography rather than a grid. A density heatmap, a two-dimensional histogram with bin counts in color, whose keys are binned continuous variables rather than categories. Just outside the chart tier, [tables.md](tables.md) names a shaded or heat-mapped table as a fifth.

**Who files what.** [Schwabish](../sources/schwabish.md) files **Heatmap** under Comparing Categories and **Correlation Matrix** under Relationship, one construction under two names. The [FT](../sources/ft-visual-vocabulary.md) splits the name three ways: **XY heatmap** under Correlation, **heat map** under Spatial, **Calendar heatmap** under Change over Time.

**What this wiki cannot settle.** Which referent the bare word takes. [heatmap.md](heatmap.md) does not resolve it. Nothing in the corpus bears on the density-heatmap sense. The filing disagreement is not a defect, since [README.md](README.md) treats these taxonomies as retrieval aids rather than facts about charts.

### "Range plot"

**The two referents.** Two dots marking the ends of a span, the drawing on [dumbbell-plot.md](dumbbell-plot.md). And an interval drawn around an estimate, a different claim: the interval says what is not known, while a dumbbell's two dots are two measurements.

**Who files what.** [Datawrapper](../sources/datawrapper-academy.md) uses the first sense in passing, explaining why the form needs no zero baseline: "Readers don't expect dot plots (or, for two values, range plots) to start at zero because there's no filled bar or column that would indicate that." It names the form again among chart types whose height is fixed by row count. Neither passage defines it. The second sense now has a page, [interval-plot.md](interval-plot.md), which the type page records from the field.

**What this wiki cannot settle.** Which sense a given person means. The type page records a caption naming which one was drawn. Datawrapper's chart-type documentation, which defines the types the product ships, would move this and is unread here.

## Names with no page here at all

Unlinked, since the pages do not exist, and grouped by the index each would go under.

**Recorded in a source read here.** Schwabish entries unless noted.

- Network and topology: arc chart (Relationship), and arc diagram, named on the network index.
- Distribution: candlestick, pyramid, stem-and-leaf.
- Magnitude: nested bubbles.
- Change over time: circular line, cycle, gantt and flow charts, timelines. Also fan chart, which the FT files there for uncertainty in projections.
- Spatial: proportional symbol map, with an FT gloss ("Use for totals rather than rates").
- Part-to-whole: tree diagram (Relationship), nightingale, voronoi, and Venn, which the FT files under Part-to-whole. Euler is not named anywhere in this corpus.
- Qualitative: word cloud, word tree, icons, quotes, coloring phrases.
- Ranking: arrow plot, from Datawrapper's resizing article.
- Isotype and pictogram share Schwabish's Unit/Isotype/Waffle entry. The FT files them under Magnitude and the grid form separately as **Gridplot** under Part-to-whole, which independently supports [waffle-chart.md](waffle-chart.md) treating them as neighbors rather than one form.

**Named in this tier, with no source behind the name.** Histogram-of-histograms (distribution). Alluvial diagram and parallel sets (flow). Biofabric, edge bundling and bipartite layouts (network and topology). Binned density plot, hexbin or 2D histogram (correlation). Column over time (change over time). Surplus and deficit filled line (deviation). Ordered proportional symbols (ranking). Grouped bars (magnitude). Icon array (qualitative). Scatterplot matrix or SPLOM, sina plot and violin scatter, each flagged on an existing page as a different construction.

For most of these the corpus holds a catalog line and nothing else, and [distribution.md](distribution.md) holds that a page is not a warrant.
